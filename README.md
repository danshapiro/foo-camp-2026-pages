# Foo Camp 2026 password-gated schedule

Public page: https://danshapiro.github.io/foo-camp-2026-pages/

This repository hosts the static password page and encrypted site payload. It does not contain the plaintext schedule, source board photos, or shared passphrase. The page decrypts the schedule in the visitor’s browser after they enter the shared passphrase; there are no visitor accounts.

Anyone who can download the encrypted payload can try passphrase guesses offline. This is suitable for sharing with attendees, not for highly sensitive information.

Issues and pull requests are welcome for the unlock page or deployment. For a schedule correction, open an issue with the relevant source image filename. Tell Dan Shapiro on Discord when you submit a pull request so he can update the private source and republish. Never include the shared passphrase or decrypted schedule in an issue or pull request.
